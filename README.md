# Debt Management

A Next.js application for tracking and managing debts.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- Track multiple debts
- Monitor payment progress
- Manage debt repayment schedules

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
